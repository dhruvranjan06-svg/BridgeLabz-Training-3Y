1. Explain the difference between frontend, backend, and full-stack development with
suitable real-world examples.

ans-:In web development, frontend and backend are two main parts of a website.
Frontend is the part which we can see and use on a website. For example, buttons, images, forms, menu, colors etc. HTML, CSS and JavaScript are mainly used for frontend development.
Backend is the part which works behind the website. It handles data, login details, requests and connection with database. Languages and technologies like Java, Python, PHP and Node.js can be used for backend.
Full-stack means working on both frontend and backend.
Example: In a shopping website, the product page and Add to Cart button are frontend, while storing user details and processing orders are backend. A developer who can work on both is called a full-stack developer.

3. Describe how a browser requests and displays a web page from a web server.
ans-:When we enter a website address in a browser, the browser first finds the server where that website is available.
Then the browser sends an HTTP or HTTPS request to the web server. The server receives the request and sends the required files such as HTML, CSS and JavaScript.
After receiving these files, the browser reads them and displays the final webpage on our screen.

5. Explain what a web server is and give examples of commonly used servers.
ans-:A web server is a software/system which receives requests from users and sends the required web content back to them.

For example, when we open a website in Chrome, the browser sends a request to the web server. The server finds the requested page or data and sends it back to our browser.

The simple working is:

Browser → Request → Web Server
Browser ← Response ← Web Server

8. Explain the difference between static and dynamic websites. Provide an example of
each.
ans-:A static website shows mostly the same content to every user. Its content does not change automatically.

Example: A simple portfolio website.

A dynamic website can show different or updated content based on the user or data.

Example: A shopping website where products, cart and user details can change.
